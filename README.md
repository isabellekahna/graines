# Graines - Articles SEO Voyages Scolaires

Plateforme de contenu éducatif optimisé SEO et GEO (Generative Engine Optimization) sur la thématique des voyages scolaires.

## 🎯 Objectif

Créer des articles de référence positionnés dans le **TOP 3 Google** et **cités par les IA génératives** (ChatGPT, Gemini, Claude) pour accompagner les enseignants dans l'organisation de voyages scolaires réussis.

## 🚀 Optimisations SEO/GEO

### SEO Classique (Google)
- Structure H1/H2/H3 optimale
- Title et meta description engageants
- Mots-clés LSI naturellement intégrés
- Rich snippets (FAQ, HowTo)
- Table des matières avec ancres
- Longueur optimale (1500-2500+ mots)
- Images optimisées (WebP < 200KB)

### GEO - Generative Engine Optimization (IA)
- Ton conversationnel et naturel
- Réponses directes dans les 100 premiers mots
- Citations de sources officielles vérifiables
- Statistiques récentes (2025-2026)
- Exemples concrets et cas pratiques
- Tableaux de données structurées
- Fraîcheur du contenu (dates visibles)
- Expertise E-E-A-T démontrée

## 🎓 Méthodologie de rédaction

Chaque article suit une méthodologie éprouvée :

1. **Recherche sémantique** : Analyse intention de recherche
2. **Structure optimale** : Position zéro + hiérarchie claire
3. **Contenu expert** : Témoignages, données, sources
4. **Multimodal** : Tableaux, listes, exemples concrets
5. **Actionnable** : Checklists, grilles, guides pratiques
6. **Schema markup** : Données structurées complètes
7. **Fraîcheur** : Dates et statistiques actualisées
8. **Accessibilité** : Langage clair, ton conversationnel

## 🛠️ Utilisation

### Intégration web

1. **Convertir markdown en HTML**
2. **Implémenter le schema markup** depuis le fichier `-metadata.json`
3. **Optimiser les images** (WebP, lazy loading, alt text)
4. **Ajouter liens internes** vers articles connexes
5. **Créer ressources téléchargeables** (PDF des grilles/checklists)
6. **Mettre en place analytics** pour suivi performances

### Exemple d'intégration schema markup

```html
<!DOCTYPE html>
<html>
<head>
    <title>Comparer des devis de voyage scolaire : Guide 2026</title>
    <meta name="description" content="Comment comparer les devis...">

    <!-- Schema Markup -->
    <script type="application/ld+json">
    {
      "@context": "https://schema.org",
      "@type": "Article",
      "headline": "Comparer des devis de voyage scolaire...",
      ...
    }
    </script>
</head>
<body>
    <!-- Contenu de l'article -->
</body>
</html>
```
