# Articles SEO - Voyages Scolaires

Ce dossier contient les articles optimisés SEO sur la thématique des voyages scolaires.

## Structure des fichiers

Chaque article est composé de :
- **[slug].md** : Contenu principal de l'article en markdown
- **[slug]-metadata.json** : Métadonnées SEO et schema markup
- **[slug]-resources/** : Ressources téléchargeables (grilles, checklists, etc.)

- ✅ Rich snippets (FAQ, HowTo)
- ✅ Table des matières avec ancres

## Notes d'implémentation

**Pour intégrer ces articles sur un site web :**

1. Convertir le markdown en HTML
2. Implémenter le schema markup dans le `<head>`
3. Optimiser les images (WebP, lazy loading)
4. Ajouter les liens internes vers articles connexes
5. Créer les ressources téléchargeables
6. Mettre en place le suivi analytics

**Exemple d'intégration schema markup :**

```html
<script type="application/ld+json">
  [Contenu du fichier -metadata.json]
</script>
```
